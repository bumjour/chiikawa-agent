01다운로드 · 설치

Windows

  1. 다운로드 페이지 bumjour.github.io/chiikawa-agent 에 들어가요.
  2. Windows 버튼을 눌러 ChiikawaAgent-Windows.exe 를 받아요. (약 115MB)
  3. 받은 파일을 더블클릭해요.
  4. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행 을 눌러요.
  5. 설치 창에서 설치 위치를 확인하고 설치 를 눌러요. 끝나면 바탕화면과 시작 메뉴에 치이카와 에이전트가 생겨요.
💡 "PC 보호" 창은 왜 뜨나요?

개인이 만든 무료 프로그램이라 마이크로소프트 유료 인증서(코드 서명)를 붙이지 않았기 때문이에요. 바이러스라는 뜻이 아니에요. 출처가 위 다운로드 페이지가 맞는지만 확인해 주세요.

macOS (맥)

  1. 다운로드 페이지에서 맥 · M1~M4 칩(ChiikawaAgent-Mac-AppleSilicon.dmg) 또는 맥 · 인텔 칩(ChiikawaAgent-Mac-Intel.dmg) 버튼을 눌러 받아요. 내 칩은 메뉴 → 이 Mac에 관하여 에서 확인해요.
  2. dmg를 열고 Chiikawa Agent(맥에서는 영어 이름이에요)를 응용 프로그램 폴더로 끌어다 놓아요.
  3. 처음 열 때 "열 수 없음" 경고가 뜨면 완료 로 닫아요. (휴지통으로 이동 은 누르지 마세요)
  4. 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기 → 암호/Touch ID → 열기
  5. 그래도 "손상되었기 때문에 열 수 없습니다"가 뜨면 응용 프로그램 → 유틸리티 → 터미널 에 아래 한 줄을 붙여넣고 Enter 후 다시 열어요.
    xattr -cr "/Applications/Chiikawa Agent.app"

02AI 키 발급

캐릭터가 말투를 살려 말하려면 AI 서비스의 API 키(비밀번호 같은 문자열)가 필요해요. 세 가지 중 하나만 있으면 돼요.

서비스비용특징
Google Gemini ⭐추천무료 등급 있음카드 등록 없이 바로 시작. 하루에 여러 번 대화해도 무료 한도 안이에요. 단, 무료 등급은 입력 내용이 구글 서비스 개선에 쓰일 수 있어요.
Anthropic Claude선불 충전캐릭터 말투 재현이 자연스러워요. 최소 충전 금액이 있어요.
OpenAI선불 충전최소 충전 금액이 있어요.

Gemini 키 만들기 (무료)

  1. aistudio.google.com 에 들어가 Google 계정으로 로그인해요. 처음이면 약관에 동의해요.
  2. 왼쪽 메뉴 Get API key → Create API key 를 눌러요.
  3. 만들어진 키 옆의 복사 버튼을 눌러요. 키는 AIza… 또는 AQ.… 로 시작해요.
  4. 치이카와 에이전트 설정 창의 AI 연결 탭에 붙여넣어요. (03 첫 설정 참고)

설정 창의 🔑 키 발급받으러 가기 버튼을 누르면 고른 서비스의 키 발급 페이지가 바로 열려요.

Claude · OpenAI 키 만들기

  • Claude: console.anthropic.com 가입 → Billing 에서 크레딧 충전 → API Keys → Create Key (키는 sk-ant- 로 시작)
  • OpenAI: platform.openai.com 가입 → Billing 에서 충전 → API keys → Create new secret key (키는 sk- 로 시작)
⚠️ 키는 비밀번호처럼 다뤄 주세요
  • 카톡·메일·채팅에 붙여넣지 마세요. 누군가 내 키로 AI를 쓰면 한도가 줄거나 요금이 나와요.
  • 키가 노출됐다면 발급 페이지에서 그 키를 삭제하고 새로 만들어 넣으면 돼요.
  • 키는 이 컴퓨터 안에만 저장되고, 개발자에게 전송되지 않아요.

03첫 설정

설치 후 처음 실행하면 캐릭터 둘(하치와레 = 일정 비서, 우사기 = AI 대화)이 화면 오른쪽 아래에 뜨고, 1초 뒤 설정 창이 열려요.

① 내 정보
② AI 연결

① 내 정보

  • 불리고 싶은 이름: 일정 브리핑·혼잣말에서 가끔 이 이름으로 불러 줘요. 대화할 때는 이름 없이 바로 대답하고, 이름을 물어보면 알려 줘요.
  • 직장인 / 학생: 시간대별 혼잣말과 대화 주제가 달라져요.
  • 혼잣말 간격: 10초 · 30초 · 1분 · 5분 · 10분(기본) · 30분 · 1시간 · 끄기

② AI 연결

  1. AI 서비스를 고르고 (기본 Gemini) 02에서 만든 키를 붙여넣어요.
  2. 연결 테스트 → "✅ 연결 성공!"이 뜨면 저장

나중에 바꾸고 싶으면 캐릭터 우클릭 → 내 정보·혼잣말 설정… 또는 AI 키 설정… 에서 언제든 고칠 수 있어요. 키가 없어도 일정 적기·목록 보기는 돼요.

04사용법 ① 일정 비서

일정 적기

오늘 일정 적기

  1. 일정 비서 캐릭터를 클릭해요. 오늘 일정이 없으면 입력칸이 바로 열려요.
    (또는 우클릭 → 오늘 일정 적기)
  2. 한 줄에 일정 하나: 왼쪽 시간, 오른쪽 내용을 적어요.
  3. 내용 칸에서 Enter → 다음 줄로, + 일정 추가 로 줄 늘리기, × 로 줄 지우기
  4. 저장하고 들려줘 (또는 Ctrl+Enter)

저장하면 시간순으로 정렬돼요. 시간을 비운 일정은 "시간 미정"으로 맨 뒤에 가요. 일정은 날짜별로 따로 저장돼서 매일 새로 적으면 돼요.

일정 브리핑

일정 듣기

  • 캐릭터를 클릭하면 오늘 전체 일정을 캐릭터 말투로 알려 줘요.
  • ⏰ 남은 일정: 지금 시각 이후 일정만, 가장 가까운 일정까지 남은 시간과 함께 알려 줘요. ↩ 돌아가기 로 처음 브리핑으로.
  • 📋 전체 일정 확인: 오늘 일정 목록을 보고 바로 고칠 수 있어요.
  • 말풍선이 떠 있을 때 캐릭터를 한 번 더 클릭하면 닫혀요. 45초 뒤엔 저절로 닫혀요.

앱을 켜자마자 오늘 일정을 미리 받아 두기 때문에, 첫 클릭부터 바로 대답해요. 같은 일정은 다시 물어봐도 즉시 나와요.

05사용법 ② AI 대화 · 혼잣말

AI 대화

대화하기

  1. AI 대화 캐릭터를 클릭하면 말풍선에 입력창이 열려요.
  2. 하고 싶은 말을 쓰고 Enter
  3. 캐릭터 말투로 대답해요. 앞의 대화를 기억하고 이어서 말해요.

질문하면 실제로 도움이 되는 답을 주되, 캐릭터답게 짧게 대답해요. 우사기처럼 외침 위주인 캐릭터는 외침 사이에 핵심만 툭 던져요.

07캐릭터 이미지 가져오기 · 배경 없애기

받자마자 7종 모두 그림이 나와요. 다른 그림으로 바꾸고 싶을 때만 아래 순서대로 하면 돼요.

캐릭터그림
치이카와 · 하치와레 · 우사기처음 켤 때 팬 사이트의 예시 GIF를 자동으로 받아 와요. 모습 고르기에서 다른 예시로 바꿀 수 있어요
모몽가 · 쿠리만쥬 · 시사 · 랏코앱에 그림이 들어 있어요. 모습 고르기에서 여러 그림 중 고를 수 있어요

① 이미지 구하기

  • 팬 사이트 chiikawawallpaper.com/ko/gif → 캐릭터별 보기에서 원하는 GIF 클릭 → 다운로드
  • 또는 이미지 검색에서 "캐릭터 이름 + png 투명"으로 찾기
✅ 잘 어울리는 이미지
  • 배경이 투명한 PNG·GIF (체크무늬 배경으로 보이는 것)
  • 몸 전체가 나온 그림 (얼굴만 크게 나온 장면 ✕)
  • 한 캐릭터만 있는 그림
모습 고르기 창

③ 앱에 넣기 (배경 없애기는 다음 쪽)

  1. 캐릭터 우클릭 → 캐릭터 바꾸기 로 원하는 캐릭터를 먼저 골라요.
  2. 우클릭 → ○○ 모습 고르기… → 위에서 🙂 평소 모습 또는 💬 말할 때 모습 선택
  3. ＋ 내 이미지 추가 로 파일 선택 → 추가된 그림(“내 이미지” 표시)을 누르면 바로 바뀌어요.

07배경 없애기

받은 이미지에 흰 바탕이나 배경이 있으면 바탕화면 위에 네모난 그림으로 떠요. 아래 방법으로 배경을 지운 뒤 PNG로 저장해서 넣어 주세요.

도구방법
Windows 그림판
PNG·JPG 한 장		이미지 우클릭 → 연결 프로그램 → 그림판 → 위쪽 이미지 → 배경 제거 → 파일 → 다른 이름으로 저장 → PNG
그림판 메뉴 위치는 업데이트에 따라 조금 다를 수 있어요. 원본을 덮어쓰지 않게 "다른 이름으로 저장"하세요.
맥 미리보기
PNG·JPG		이미지 더블클릭(미리보기) → 위 메뉴 도구 → 배경 제거 → 저장
여러 장은 Finder에서 선택 → 우클릭 → 빠른 동작 → 배경 제거
remove.bg
웹, 사진 한 장		remove.bg 에 이미지 올리기 → 자동으로 배경 제거 → Download
ezgif
웹, 움직이는 GIF		ezgif.com → Remove background → GIF 올리기 → 지울 배경색 선택(흰색 등) → fuzz로 비슷한 색까지 범위 조절 → Submit → 저장
배경이 한 가지 색(흰 바탕 등)일 때만 깔끔해요. 나무·하늘이 있는 애니 장면 GIF는 배경이 남아서 추천하지 않아요. 결과가 깜빡이면 ezgif의 optimize → unoptimize 를 먼저 해 보세요.
💡 어떤 방법을 고를까요?
  • 멈춰 있는 그림(PNG·JPG) → 그림판(Windows) · 미리보기(맥) · remove.bg 중 편한 것
  • 움직이는 GIF + 흰색 같은 단색 배경 → ezgif
  • 움직이는 GIF + 나무·하늘 같은 복잡한 배경 → 깔끔하게 지우기 어려워요. 같은 캐릭터의 투명 PNG를 찾는 걸 추천해요.

원본 파일은 남겨 두고 다른 이름으로 저장하세요. JPG로 저장하면 투명한 부분이 다시 흰색이 돼요. 꼭 PNG(움직이는 건 GIF)로 저장하세요.

08문제 해결

증상해결
설치할 때 "PC 보호" 창이 떠요추가 정보 → 실행 (01 참고)
캐릭터가 안 보여요이미 켜져 있을 수 있어요. 화면 오른쪽 아래를 확인하고, 그래도 없으면 시작 메뉴에서 다시 실행하세요. 여러 모니터를 쓰다 하나를 뺐다면 우클릭 → 고급 → 설정 파일 열기 에서 "positions" 내용을 {} 로 비우고 다시 시작하세요.
"AI 연결 실패: 429"무료 한도(1분당 요청 수)를 넘었어요. 1분쯤 뒤 다시 눌러 주세요. 자주 그러면 혼잣말 간격을 10분 이상으로 늘려 주세요.
"AI 연결 실패: 503 / 응답 시간 초과"AI 서버가 혼잡해요. 앱이 자동으로 다른 모델로 넘어가니 잠시 뒤 다시 시도하세요.
"400 / API key not valid"키가 틀렸거나 삭제됐어요. AI 키 설정… 에서 새 키를 넣고 연결 테스트하세요.
캐릭터가 임시 그림으로 나와요인터넷 연결을 확인하세요. 치이카와·하치와레·우사기는 처음 켤 때 그림을 받아 와요.
새 버전은 어떻게 받아요?새 버전이 나오면 캐릭터가 말풍선으로 알려 줘요. Windows는 ⬆️ 지금 업데이트 를 누르면 저절로 설치하고 다시 켜져요. 맥은 ⬇️ 새 버전 받으러 가기 를 눌러 다운로드 페이지에서 받아 덮어 설치하세요. (0.2.4부터 지원 · 그 전 버전은 한 번만 새로 받아 주세요)
말풍선이 화면 위로 잘려요캐릭터를 꾹 눌러 화면 아래쪽으로 옮겨 주세요. 말풍선은 캐릭터 위로 떠요.
컴퓨터가 느려진 것 같아요캐릭터는 가끔만 움직이도록 만들어 부담이 작아요(CPU 1~5%). 그래도 느리면 우클릭 → 종료 후 필요할 때만 켜 주세요.
처음부터 다시 설정하고 싶어요프로그램을 끄고 설정 폴더의 config.json 을 지운 뒤 다시 켜요.
Windows: %APPDATA%\치이카와 에이전트 · 맥: ~/Library/Application Support/Chiikawa Agent

문제가 계속되면 설정 폴더의 agent.log 파일에 기록이 남아 있어요. 다운로드 페이지의 Issues에 증상과 함께 남겨 주세요. (로그에 API 키는 기록되지 않아요)

저작권

  • 「ちいかわ」 캐릭터와 관련된 모든 권리는 원작자 nagano 및 권리자에게 있어요.

  • 직접 넣은 이미지는 개인적으로만 사용하고, 다시 배포하지 말아 주세요.
  • 권리자의 요청이 있으면 즉시 배포를 중단해요.
